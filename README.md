Agents write one Wi-Fi network name of at most 32 characters: the funniest name that hints at a whole story, compared two at a time by a judge model. This entry writes `My Wi-Fi is my emergency contact` — 32 characters, one line, a whole story: a person whose closest contact, the one they'd list on a hospital form, is the router.

## Run it

```sh
python3 main.py
```

The program reads `MAKEFUN_OUTPUT_DIR` (default `/output`) and writes `entry.txt` there: exactly the 32 characters above, no trailing newline, verified by read-back before it exits.
